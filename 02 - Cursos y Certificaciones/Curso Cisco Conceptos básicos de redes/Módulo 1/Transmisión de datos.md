# 2 Transmisión de datos

## 2.1 El bit

Todos nuestros datos se almacenan y transmiten como una serie de bits en binario (*unidad básica de información que representa uno de dos estados discretos*), ya que las computadoras solo interpretan patrones de bits.

Cada dispositivo de entrada (mouse, teclado, receptor activado por voz) traduce la interacción humana al código binario para que la CPU la procese y guarde. Cada dispositivo de salida (impresora, altavoces, monitores, etc.) toma los datos binarios y los traduce nuevamente a la forma humana que podemos reconocer. 

Las computadoras para representar e interpretar letras, números, caracteres, contenido multimedia, para que nosotros podamos verlo en ves de 0s y 1s, utilizan el  código ASCII. En ASCII, cada caracter está representado por ocho bits. Por ejemplo:

- **Mayúscula:** A = 01000001
- **Número:** 9 = 00111001
- **Carácter especial:** # = 00100011

Los códigos se pueden usar para representar casi cualquier tipo de información en formato digital: datos informáticos, gráficos, fotos, voz, video y música.

## 2.3 Métodos Comunes de Transmisión de Datos

Una vez transformados los datos a una serie de bits, se los debe convertir en señales para poder enviarlos a través de medios como cable de cobre, cable de fibra óptica y ondas electromagnéticas por el aire. Una señal está compuesta por patrones eléctricos u ópticos (serie de pulsos de electricidad, de pulsos de luz o de ondas de radio) que se transmiten de un dispositivo conectado a otro.

Se utilizan tres métodos comunes para transmitir señales en las redes:

- **Señales eléctricas:** La transmisión se realiza representando los datos como pulsos eléctricos que viajan por un cable de cobre. Usada en casas y oficinas pequeñas para los puestos de trabajo.
- **Señales ópticas:** La transmisión se realiza convirtiendo las señales eléctricas en pulsos de luz. Usada para redes grandes con cables de fibra para mayor confiabilidad para conexiones a una larga distancia. 
- **Señales inalámbricas:** La transmisión se realiza por medio de ondas infrarrojas, de microondas o de radio por el aire. Usada para WI-FI para dispositivos móviles o netbooks.
