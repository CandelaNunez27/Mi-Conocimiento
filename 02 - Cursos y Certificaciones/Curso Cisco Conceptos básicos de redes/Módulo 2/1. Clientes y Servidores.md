# 1. Clientes y Servidores

## 1.1 Roles de cliente y servidor

El software que tenga instalado la computadora es el rol que desempeñara, siendo host que pueden enviar y recibir mensajes através de la red. 
- **Servidores:** *son los host que tienen softaware instalado que les permite proporcionar información a los clientes. Como servidores de correo o páginas web.*
- **Clientes:** *son los host que tienen software instalado que les permite solicitar y mostrar la infromación obtenido de los servidores. Como los navegadores web o clientes de correo electronico.*

### 1.2 Redes entre pares

Usualmente el servidor  y el cliente son PCs distintas, pero puede una PC ser ambas usualmente en empresas y hogares.  *Llamas red entre pares (peer-to-peer o P2P) que consiste en dos computadoras (o más si se tiene un conmutador) conectadas directamente por cable o inalámbrica. Ambas usan la red para intercambiar entre sí, siendo servido o cliente segun la necesidad*. Pero tiene la desventaja del rendimiento de un host puede verse afectado si éste activa el cliente y servidor a la vez, y para empresas grandes se necesitan servidores dedicados por su alto trafico. 

![](../../../04%20-%20Otros/Imagenes/Pasted%20image%2020260908040324.png)

### 1.3 Aplicaciones entre pares

Aplicaciones P2P permite que un dispositivo funcione como cliente y servidor dentro de la misma comunicación utilizando un sistema híbrido donde se descentraliza el intercambio de recursos, pero los índices que apuntan a las ubicaciones de los recursos están almacenados en un directorio centralizado. Cada uno accediendo al servidor de índice para obtener la ubicación de un recurso almacenado en otro punto.

![](../../../04%20-%20Otros/Imagenes/Pasted%20image%2020260908041754.png)

### 1.4 Múltiples Roles en la Red

Una computadora con software de servidor puede proporcionar servicios simultáneamente a uno o muchos clientes. Además, una única PC puede ejecutar varios tipos de software de servidor. En una negocio doméstico o pequeño, puede ser necesario que una PC funcione como servidor de archivos, servidor web y servidor de correo electrónico.

Una única PC también puede ejecutar varios tipos de software de cliente. Debe haber un software de cliente para cada servicio requerido. Si un host tiene varios clientes instalados, puede conectarse a varios servidores de manera simultánea. Por ejemplo, un usuario puede consultar el correo electrónico y ver una página web mientras envía mensajes instantáneos y escucha la radio por Internet.
