
1) **¿Qué tipo de red está definida por dos computadoras que pueden enviar y recibir solicitudes de recurso?**
	 Entre pares.

2) **¿Cuáles de las siguientes son dos funciones de los dispositivos finales en una red?**
	Constituyen la interfaz entre los humanos y la red de comunicación y Dan origen a los datos que fluyen por la red.

3) **Un usuario particular está buscando una conexión ISP que proporcione transmisión digital de alta velocidad en líneas telefónicas comunes. ¿Qué tipo de conexión ISP debe utilizar?**
	DSL.

4) **¿Qué tipo de conexión a internet sería el más adecuado para una residencia en un área remota sin cobertura de telefonía móvil ni conectividad cableada?**
	Red satelital.

5) **¿Qué término describe correctamente la función de un ISP?**
	Responsable de proporcionar el enlace entre una red privada e Internet.

6) **¿Qué dispositivo es un dispositivo intermediario?**
	Cortafuegos.

7) **¿Qué situación describe una red entre pares?**
	Se instala de forma directa sobre el hardware físico del equipo y es el más eficiente.

8) **¿Cuál de las siguientes es una característica técnica que define a una Nube Pública?**
	Los servicios se ofrecen a través de internet público y son compartidos por múltiples organizaciones (multi-tenancy).

9) **Si tu organización adquiere otra empresa en Azure y quieres que los servidores virtuales de ambas redes se comuniquen directamente usando direcciones IP privadas sin salir al internet público, ¿qué mecanismo de red debes usar?**
	VNet Peering.

10) **Según el ecosistema estratégico actual de proveedores cloud (hacia 2026), ¿cuál de los siguientes mantiene el liderazgo global en cuota de mercado con alrededor de un 31%?**
	  Amazon Web Services (AWS).

11) **En un entorno de Plataforma como Servicio (PaaS), tú eres el responsable de instalar y gestionar el sistema operativo, el servidor web y el entorno de ejecución, ya que el proveedor solo se limita a entregarte el hardware.**
	Falso.

12) **La virtualización surgió como el corazón de la nube para solucionar el desperdicio de los recursos físicos, permitiendo ejecutar múltiples máquinas virtuales dentro de un solo servidor físico.**
	Verdadero.

13) **Si tu empresa contrata infraestructura bajo un modelo IaaS (como una instancia EC2 en AWS), el proveedor de la nube se encarga de administrar, actualizar y parchear automáticamente tu sistema operativo.**
	Falso.

14) **A nivel de virtualización, el hipervisor de Tipo 2 (Hosted) se instala como una aplicación regular sobre un sistema operativo tradicional (como Windows), y algunos ejemplos de esto son VirtualBox o VMware Workstation.**
	Verdadero.

15) **¿Por qué razón ciertas industrias muy reguladas (como bancos o centros de salud) a menudo prefieren seguir alojando sus sistemas ERP centrales en una infraestructura On-Premise en lugar de la Nube Pública?**
	  Para integrar sus procesos asegurando un control físico, exclusivo y estricto sobre todos sus datos confidenciales.

16) **En el modelo de Software como Servicio (SaaS), ¿de qué aspecto es responsable el usuario final?**
	Únicamente de realizar las configuraciones básicas de su cuenta de usuario.

17) **El modelo de infraestructura "On-Premise" significa que el software y la infraestructura están alojados dentro de las instalaciones físicas o el centro de datos de la empresa.**
	Verdadero.

18) **Para evitar la dependencia tecnológica con un solo proveedor (Vendor Lock-in), se recomienda firmar contratos de uso exclusivo a largo plazo en lugar de usar despliegues de contenedores como Kubernetes.**
	Falso.

19) **Según el "Modelo de Responsabilidad Compartida", si borras una base de datos por accidente en la nube, el proveedor asume la culpa y es responsable de recuperar tu información.**
	Falso.

20) **¿Qué beneficio principal aportan los procesadores Graviton4 en la infraestructura de cómputo de AWS?**
	Permiten un ahorro de costos de hasta el 40% frente a la arquitectura x86 tradicional.
