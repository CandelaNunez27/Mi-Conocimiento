# 3. Estándares inalámbricos

### 3.1 Redes WI-FI

Los estándares son para que los dispositivos inalámbricos puedan comunicarse definiendo el espectro de Radio Frecuencia (RF), las velocidades de transmisión, cómo se transmite, etc.  Siendo el Instituto de Ingenieros Electrónicos y Electrónicos (IEEE) la principal que los crea.

**IEEE 802.11:** para entornos WLAN, describiendo las características de las comunicaciones inalámbricas de 2.4 GHz y 5 GHz, o sea el WI-FI.

Otra organización es Alianza WIFI que son los que prueban los dispositivos fabricados y se les coloca el logo de WI-FI cuando cumple estos estándares.

### 3.2 Configuración Inalámbrica

Packet Tracer:

- **Modo de red**: Determina el estándar 802.11 que admite el AP (802.11b, g, n, ac, ax, etc.). Si todos los dispositivos usan el mismo estándar, se alcanza la velocidad máxima de ese estándar. En modo mixto se admiten varios estándares simultáneamente, lo que permite la conexión de dispositivos antiguos pero limita el rendimiento global.
  
- **Nombre de la red (SSID)**: Cadena alfanumérica de hasta 32 caracteres (sensible a mayúsculas/minúsculas) que identifica la WLAN. Se incluye en el encabezado de todas las tramas. Todos los dispositivos que deseen participar deben tener el mismo SSID.
  
- **Canal estándar:** Especifica el canal en el que se llevará a cabo la comunicación. La configuración predeterminada está establecida en Auto para permitir que el AP determine el canal óptimo para usar.
  
- **Difusión de SSID:** Determina si el SSID (Identificador de Conjunto de Servicios) se transmitirá a todos los dispositivos dentro del alcance. De manera predeterminada está Activado (Enabled)

En redes inalámbricas 802.11, el modo de red determina qué estándar WiFi utiliza la WLAN. Si todos los dispositivos comparten el mismo estándar, se logra la velocidad máxima de ese estándar; en modo mixto, se admiten varios estándares simultáneamente para dar compatibilidad con dispositivos antiguos, aunque esto limita las velocidades máximas. 

El SSID es el nombre alfanumérico (hasta 32 caracteres, sensible a mayúsculas/minúsculas) que identifica la red y se incluye en el encabezado de cada trama. Los routers lo difunden por defecto para que los dispositivos lo detecten automáticamente; si se deshabilita la difusión, hay que ingresarlo manualmente. Ocultar el SSID no garantiza seguridad: la protección real debe lograrse mediante el cifrado más fuerte disponible (WPA2/WPA3).
