1) **¿Cuál es la función principal de un hipervisor en la infraestructura on-premise?**
	 Permitir que múltiples sistemas operativos compartan el mismo hardware físico.

2) **En el modelo de responsabilidad compartida, ¿de qué es responsable típicamente el cliente en un servicio IaaS?**
	Gestión de SO, Aplicaciones y Configuración de red.

3) **Dentro de los fundamentos de redes en la nube, ¿qué función cumple una VPC o VNet?**
	Proporcionar una red lógica aislada dentro de la nube pública.

4) **¿Qué estrategia del Framework 6R de migración implica mover aplicaciones a la nube sin realizar cambios en su código?**
	REHOST (lift and Shift).

5) **En una arquitectura escalable, ¿cuál es la diferencia entre escalabilidad vertical y horizontal?**
	La horizontal añade más instancias al pool, la vertical aumenta los recursos de una instancia existente.

6) **¿Qué patrón de microservicios evita que una falla en un servicio secundario cause una caída en cascada en todo el sistema?**
	Circuit Breaker.

7) **¿Cuál es la característica fundamental de la Infraestructura como Código (IaC) en herramientas como Terraform?**
	Idempotencia: ejecutar el código varias veces produce el mismo resultado final.

8) **¿Qué componente de Kubernetes se encarga de mantener el estado deseado de los pods dentro de un nodo?**
	Kubelet.

9) **En seguridad en la nube, ¿qué significa el principio de 'Menor Privilegio' (Least Privilege)?**
	Otorgar solo los permisos estrictamente necesarios para que el usuario realice su tarea.

10) **¿Qué métrica define el tiempo máximo que una organización puede permitirse estar sin servicio después de un desastre?**
	  RTO (Recovery Time Objective).

11) **¿Cuál es el objetivo principal de la metodología FinOps en la gestión de la nube?**
	Fomentar la responsabilidad financiera y la optimización de costos en tiempo real.

12) **En un pipeline de CI/CD, ¿qué fase se encarga de integrar el código nuevo en el repositorio principal y ejecutar pruebas automáticas?**
	Continuous Integration (CI).

13) **¿Para qué sirve el etiquetado (tagging) de recursos en una estrategia multi-cloud?**
	Para organizar, asignar costos y gestionar la seguridad de forma coherente.

14) **¿Cuál es la principal ventaja de utilizar contenedores (Docker) frente a máquinas virtuales tradicionales?**
	Mayor eficiencia de recurso y tiempo de arranque mucho más rápidos.

15) **En el contexto de serverless, ¿por qué se dice que el escalado es 'transparente' para el desarrollador?**
	  Para integrar sus procesos asegurando un control físico, exclusivo y estricto sobre todos sus datos confidenciales.

16) **En el modelo de Software como Servicio (SaaS), ¿de qué aspecto es responsable el usuario final?**
	Únicamente de realizar las configuraciones básicas de su cuenta de usuario.

17) **El modelo de infraestructura "On-Premise" significa que el software y la infraestructura están alojados dentro de las instalaciones físicas o el centro de datos de la empresa.**
	Verdadero.

18) **Para evitar la dependencia tecnológica con un solo proveedor (Vendor Lock-in), se recomienda firmar contratos de uso exclusivo a largo plazo en lugar de usar despliegues de contenedores como Kubernetes.**
	Falso.

19) **Según el "Modelo de Responsabilidad Compartida", si borras una base de datos por accidente en la nube, el proveedor asume la culpa y es responsable de recuperar tu información.**
	Falso.

20) **¿Qué beneficio principal aportan los procesadores Graviton4 en la infraestructura de cómputo de AWS?**
	Permiten un ahorro de costos de hasta el 40% frente a la arquitectura x86 tradicional.
